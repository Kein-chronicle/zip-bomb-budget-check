# Security

Use synthetic examples when reporting issues. Do not post credentials or personal documents. If private reporting is enabled on the repository, use its Security tab; otherwise request a private contact method without posting exploit details.

These are local reference tools, not a sandbox or security certification. Only execute trusted scripts and gate specifications. Inspect code before granting filesystem, shell, network or scheduling access. Treat input documents and model outputs as data, not authorization. Read the limitations in SKILL.md and README.md.
