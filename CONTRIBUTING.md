# Contributing

Issues and pull requests are welcome.

1. Run the tests before and after your change: `python3 tests/run.py`
2. Add a test for every behavior you change, including an input that must be rejected.
3. Keep the examples in `examples/` runnable; the README output is generated from them.
4. Do not commit secrets, personal data, absolute local paths or third-party assets you do not have the right to redistribute.
